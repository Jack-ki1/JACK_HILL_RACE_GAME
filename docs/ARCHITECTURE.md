# System Architecture

## Layer Separation
1. **3D Perspective Dual-Angle Rendering Layer (`src/game/worldScene.ts`, `src/game/garageScene.ts`, `src/game/models.ts`, `src/game/textures.ts`)**
   - `WorldSceneController` owns a dedicated WebGL2 canvas isolated outside React reconciliation using a responsive `THREE.PerspectiveCamera` (`TITLE`: low front-right 3/4 rock-crawling hero shot; `PLAYING`: dynamic 2.5D perspective chase camera with look-ahead and speed/big-air pull-back).
   - Implements automatic software-WebGL detection (`SwiftShader`/`llvmpipe`) with `afterDraw` fence pacing so virtual environments remain responsive without GPU queue stalls.
   - Uses `RoomEnvironment` PMREM lighting, `SRGBColorSpace` output, `ACESFilmicToneMapping`, dynamic shadow frustum tracking, 5-octave FBM sky shader oriented along camera view direction, terrain surface vertex tinting (`mud`, `sand`, `ice`, `wood`, `rock`), reusable object pools (coins, fuel cans, faceted rock outcrops, scrub grass tufts, bridges, tunnels, milestone signs), and a 360-instance `InstancedMesh` particle buffer with zero allocations inside `tick()`.
   - Supports configurable track competition (`rivalMode: 'ai' | 'ghost' | 'off'`): an electric cyan 3D **AI Racer** (`aiRig` driven live by `HillClimbPhysics` + `computeAiDriverControl` at `z = -1.75`) or personal-best amber **Ghost Replay** (`0.12s` samples up to `2500` frames) strictly during `PLAYING` mode.
2. **180Hz Physics, Terrain & Autonomous AI Layer (`src/game/physics.ts`, `src/game/terrain.ts`, `src/game/aiAgent.ts`)**
   - `terrain.ts` evaluates continuous C2-smooth Perlin gradient FBM hills (`perlin1D`, `fbmPerlin1D`) with 100m cosine difficulty chunks, surface tangent/normal `(tx, ty, nx, ny)`, wooden bridge sag, slick ice, mud bogs (`muMult: 0.60`), deep sand dunes, cave tunnels, collectible slot layouts, and fast lookahead ray profiles (`sampleLookaheadProfile`) in realistic meters (`1 unit = 1m`, `+Y` up).
   - `HillClimbPhysics` steps at `1/180s` fixed increments inside an accumulator loop, simulating up to 3 equipped **Tuning Parts** (`landing_boost`, `wings`, `overcharged_turbo`, `coin_boost`, `jump_shocks`, `winter_tires`), 4x4 low-range steep climb torque, mud/sand rolling drag, first-hit breakable **Rollcage** (`rollcageIntact`), close-call stunt recovery, and 4.2s **Stunt Combo** chains (`1x–5x`).
   - `aiAgent.ts` (`computeAiDriverControl`) drives both the live AI Rival and toggleable player **AI Auto-Drive** (`[I]` / `AUTO`) using forward lookahead slope sensing, airborne PD landing-tangent alignment, wheelie/backflip anti-loop-out guards, `jump_shocks` crest/mud launches, and steep climb nitro bursts.
3. **Zero-Re-Render Gameplay HUD (`src/components/GameplayHud.tsx`)**
   - Exposes `updateLive(HudLiveSnapshot)` via `useImperativeHandle` + direct DOM/SVG refs so `RPM`, `KM/H`, `BOOST` needles, `TURBO` overdrive bar, fuel bar, `FUEL IN Xm`, `AI / RIVAL +/-Xm`, surface hazard badges (`MUD BOG`, `DEEP SAND`, `SLICK ICE`, `CAVE TUNNEL`), `COMBO xN`, `AUTO` toggle, conditional `JUMP` button, and distance counters animate at 60fps without triggering React renders.
4. **Application State & Persistence (`src/App.tsx`, `src/game/storage.ts`, `src/game/constants.ts`)**
   - Coordinates game screens (`TITLE_MENU`, `PLAYING`, `PAUSED`, `GAME_OVER`, `GARAGE`, `UPGRADES`, `WORLD_MAP`, `SHOP`, `MISSIONS`, `TUNING`, `SETTINGS`) with `Teko` + `Outfit` + `JetBrains Mono` industrial typography, keyboard/pointer/gamepad inputs with window/visibility/screen-change input clearing, `SoundEngine`, and `localStorage` serialization (`hcr3_frontier_save_v1`) including date-keyed Daily Challenge rollover (`refreshDailyChallenge`) and backwards-compatible tuning part/rival migrations.
